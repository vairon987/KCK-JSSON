Kenalan dengan JSON

Format data yang sering dipakai, termasuk di addon Minecraft Bedrock.

Data, bukan bahasa pemrograman

01 · Nama dan ekstensi file

Nama file bebas, tetapi ekstensi harus tepat .json. Ekstensi adalah bagian akhir nama file yang menunjukkan formatnya.

CONTOH NAMA FILE
vairon ganteng.json
data-pemain.json
config.json

Benar: data.jsonSalah: data.json1Salah: data. Json

Catatan: beberapa sistem operasi menyembunyikan ekstensi. Pastikan nama lengkapnya benar, bukan hanya tampilan namanya.

02 · Bentuk dasar JSON

JSON adalah singkatan dari JavaScript Object Notation. Umumnya data object dibuka dengan { dan ditutup dengan }. JSON juga bisa berupa array yang dibuka dengan [ dan ditutup dengan ].

JSON VALID
{
  "nama": "Vairon",
  "level": 10,
  "aktif": true
}
Setiap kurung pembuka harus punya pasangan penutup. Koma memisahkan pasangan key-value, tetapi jangan menaruh koma setelah item terakhir.

03 · Lima hal yang wajib diingat

  • Key atau nama properti harus berupa string, memakai tanda kutip ganda.
  • String juga memakai tanda kutip ganda, misalnya "halo".
  • Number ditulis tanpa tanda kutip: 25, 3.14.
  • Boolean hanya true atau false, tanpa tanda kutip.
  • Gunakan koma di antara properti atau item, bukan setelah yang terakhir.

04 · Contoh salah dan perbaikannya

SALAH ❌
{
  "nama": "Vai"
  "level": 10,
  "aktif": "true",
}
BENAR ✓
{
  "nama": "Vai",
  "level": 10,
  "aktif": true
}

Versi benar menambahkan koma yang hilang, dan mengubah boolean dari string menjadi nilai boolean.

05 · JSON boleh bersarang (nested)

Object dapat berisi object lain atau array. Yang penting, setiap pembuka punya penutup dan sintaksnya tetap valid.

DATA BERTINGKAT
{
  "judul": {
    "daftar": [
      { "nama": "Vairon" },
      { "level": 10 },
      { "aktif": true }
    ],
    "catatan": "Belajar JSON"
  }
}

JSON tidak mengharuskan setiap object punya judul. Bentuknya mengikuti struktur data yang dibutuhkan.

Bagian 2

Masuk ke JavaScript

JavaScript (JS) adalah bahasa pemrograman yang bisa menjalankan logika.

Baca · Pahami · Coba

Tipe data dasar

String Teks yang dibungkus tanda kutip.

const nama = "Vairon";

Number Angka, tidak perlu tanda kutip.

let umur = 22;

Boolean Nilai benar atau salah.

const aktif = true;
const tidur = false;

Ingat perbedaannya

const level = 10;       // number
const levelTeks = "10"; // string
const online = true;    // boolean
const onlineTeks = "true"; // string

Walaupun terlihat mirip, 10 dan "10" punya tipe berbeda. Begitu juga true dan "true".

Komentar dimulai dengan //. Komentar membantu manusia membaca kode dan tidak dijalankan sebagai instruksi.

Console.log()

console.log() menampilkan nilai ke console. Berguna untuk memeriksa isi variable atau mencari sumber bug saat debugging.

JAVASCRIPT
console.log("Halo! Saya ganteng");

Output-nya

Halo! Saya ganteng

Bisa juga menampilkan beberapa nilai sekaligus:

const nama = "Vairon";
console.log("Nama:", nama);
console.log("Level:", 10);

Variable itu wadah

Variable menyimpan nilai supaya bisa dipakai lagi.

let umur = 17;
umur = 18; // boleh diubah

const nama = "Vairon";
// nama = "Yuki"; // error

let dipakai jika nilainya akan diubah. const dipakai jika nama variable tidak akan diberi nilai ulang.

Kenapa ada dua?

  • let skor = 0, lalu skor bisa diubah menjadi 10.
  • const nama = "Vai", variable nama tidak bisa diberi nilai ulang.
  • const pada object/array tidak membuat seluruh isinya otomatis beku. Properti atau item masih bisa diubah.
Untuk pemula, mulai dengan const. Ganti ke let saat kamu memang perlu memberi nilai ulang.

Object = lemari berlabel

Object menyimpan data dengan pasangan key dan value. Ambil nilainya menggunakan titik atau bracket.

const player = {
  name: "Vai ganteng",
  level: 10,
  ganteng: true
};

console.log(player.name);
console.log(player.level);

Output: Vai ganteng, lalu 10.

Array = rak bernomor

Array menyimpan kumpulan item dalam urutan. Nomor indeks dimulai dari 0.

const daftarItem = [
  "pedang",
  "apel",
  "kontci"
];

console.log(daftarItem[0]); // pedang
console.log(daftarItem[1]); // apel
console.log(daftarItem[2]); // kontci
Indeks 0 adalah item pertama. Array tidak mulai menghitung dari 1, karena JavaScript punya kebiasaan kecil yang suka bikin pemula mengernyit.

If / Else = pengambilan keputusan

if menjalankan blok jika kondisi benar. else menjalankan blok alternatif jika kondisi salah.

let apel = 10;

if (apel === 10) {
  console.log("Apel ada 10!");
} else {
  console.log("Jumlah apel bukan 10.");
}

Operator yang sering dipakai

  • === sama persis
  • !== tidak sama
  • > lebih besar
  • < lebih kecil
  • >= lebih besar atau sama
  • <= lebih kecil atau sama
Pada contoh apel, gunakan apel === 10 jika maksudnya jumlah apel tepat 10. Kondisi apel > 10 hanya benar jika jumlahnya lebih dari 10.
